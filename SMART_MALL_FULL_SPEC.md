## 1. 🌐 WEBSITE KHÁCH HÀNG (Customer Web)

### 1.1 Trang Chủ (Homepage)
- **Banner Hero**: Slider tự động, video background, CTA overlay, responsive mobile/desktop
- **Slider**: Đa vị trí (top/middle/sidebar), tốc độ, loop, autoplay
- **Popup**: Chào mừng, khuyến mãi, 18+ confirm, cookie consent, exit intent, quay vòng quà
- **Khuyến mãi**: Deal nổi bật, hot deals, deal theo danh mục/cửa hàng
- **Flash Sale**: Countdown timer real-time, giới hạn số lượng, % đã bán, socket live update
- **Voucher nổi bật**: Carousel, click nhận ngay, điều kiện áp dụng
- **Tin tức / Event**: Grid bài viết, card event sắp tới, countdown event
- **Cửa hàng nổi bật**: Grid/List/Map view, lọc theo tầng/danh mục, badge HOT/NEW/SALE
  - Nhà hàng: Rating, menu preview, giờ mở cửa, đặt bàn nhanh
  - Rạp phim: Phim đang chiếu, lịch chiếu, đặt vé
  - Game Center: Thể loại game, giá giờ chơi, booking slot
- **Dịch vụ**: ATM, wifi, toilet, thang máy, bãi đỗ xe, phòng y tế, phòng cho con bú
- **Bản đồ**: Bản đồ tầng tương tác, tìm cửa hàng theo tầng, chỉ đường indoor
- **Video**: Gallery video nổi bật, video cửa hàng/sự kiện, YouTube/Vimeo embedded
- **Blog**: Danh sách bài, lọc chủ đề, tìm kiếm, phân trang, bài liên quan
- **AI Chat**: Widget nổi góc màn hình, voice-to-text, gợi ý câu hỏi nhanh
- **QR Check-in**: Quét QR check-in sự kiện / loyalty điểm danh
- **QR Thanh toán**: Thanh toán bằng QR (VietQR, MoMo, ZaloPay)

### 1.2 Tài Khoản (Authentication & Profile)

#### Đăng ký / Đăng nhập
- Đăng ký Email + OTP xác thực; Đăng nhập Email/SĐT + mật khẩu
- OTP qua SMS & Email, countdown resend 60s, 2FA tùy chọn
- Google OAuth2, Facebook Login, Apple Sign-in (iOS)
- Quên mật khẩu (email link / SMS OTP); Đổi mật khẩu; Xác thực Email

#### Hồ Sơ Cá Nhân
- Avatar: Upload, crop, zoom; AI auto-crop khuôn mặt
- Thông tin: Họ tên, ngày sinh, giới tính, SĐT, email
- Điểm thưởng: Số dư, lịch sử tích/tiêu, điểm sắp hết hạn, cách kiếm
- Membership: Hạng hiện tại, tiến trình lên hạng, lợi ích hạng, badge
- Voucher: Danh sách, lọc theo loại/trạng thái, copy mã, áp dụng
- Gift Card: Số dư, lịch sử sử dụng, nhận gift card được tặng
- E-Wallet: Số dư, lịch sử giao dịch, nạp/rút tiền
- Đơn hàng: Theo trạng thái, theo dõi real-time, đổi trả, hóa đơn điện tử
- Wishlist: Sản phẩm yêu thích, thêm/xóa, chia sẻ danh sách
- Thông báo: Danh sách, phân loại (đơn/khuyến mãi/hệ thống), đánh dấu đọc, xóa
- Địa chỉ: Danh sách giao hàng, thêm/sửa/xóa, đặt mặc định, Google Maps

### 1.3 Cửa Hàng (Store)
- **Danh sách**: Lọc tầng/danh mục/đánh giá/giá; Sắp xếp; Map/List/Grid view
- **Chi tiết cửa hàng**:
  - Logo, banner, gallery ảnh/video; Giờ mở cửa, hotline, website, FB/IG/TikTok
  - Vị trí indoor map, nút Chỉ đường; Sản phẩm, Review & Rating, Voucher, Sự kiện
  - Nút gọi điện, nhắn tin, follow shop
  - AI Recommendation: Cửa hàng tương tự

### 1.4 Sản Phẩm (Product)
- **Danh mục**: Cây đa cấp, breadcrumb, icon, banner danh mục
- **Bộ lọc**: Danh mục, thương hiệu, giá, thuộc tính, rating, cửa hàng, kho, new/sale
- **AI Search**: Semantic search, image search, autocomplete, lịch sử tìm kiếm
- **Chi tiết sản phẩm**:
  - Gallery đa ảnh, zoom, 360° view, video sản phẩm
  - Giá: Gốc, sale, bulk pricing, giá thành viên
  - Thuộc tính: Lựa chọn màu/size/variant, bảng size
  - Kho: Badge "Sắp hết" / "Hết hàng" / "Đặt trước"
  - Bình luận hỏi đáp; Đánh giá 5 sao (ảnh/video), lọc theo sao
  - AI: "Sản phẩm tương tự", "Thường mua cùng", "Xem gần đây"
  - Chia sẻ (Facebook, Zalo, copy link); Wishlist toggle

### 1.5 Giỏ Hàng & Thanh Toán
- **Giỏ hàng**: Thêm/xóa/cập nhật số lượng, lưu cross-device, mini cart header
- **Checkout**:
  - Áp dụng Voucher (mã / danh sách có thể dùng)
  - Dùng Điểm thưởng (quy đổi điểm → tiền)
  - Dùng Gift Card (nhập mã / chọn từ ví)
  - Chọn địa chỉ giao hàng, phương thức vận chuyển
- **Phương thức thanh toán**:
  - COD; VNPay (QR, ATM, Visa, Master); MoMo; ZaloPay
  - Visa / Mastercard quốc tế; QR (VietQR); E-Wallet nội bộ; Trả góp (BNPL)

### 1.6 Đơn Hàng
- Theo dõi real-time (tracking timeline); Chi tiết đơn đầy đủ
- Đổi trả: Yêu cầu, chọn lý do, upload ảnh, theo dõi hoàn tiền
- Hóa đơn điện tử PDF, gửi email; Đánh giá sau nhận hàng; Reorder

### 1.7 AI Assistant
- Chat đa lượt, ghi nhớ context, markdown response
- Gợi ý chip câu hỏi nhanh, gợi ý sản phẩm/cửa hàng trong chat
- Tìm cửa hàng bằng ngôn ngữ tự nhiên; Chỉ đường Indoor Navigation
- FAQ động, chính sách, knowledge base tự cập nhật

### 1.8 Loyalty Program
- Tích điểm: Mua hàng, đánh giá, check-in, giới thiệu bạn
- Đổi quà: Catalog, lọc theo điểm, yêu cầu đổi, theo dõi tiến trình
- Điểm thưởng: Số dư, lịch sử, điểm sắp hết hạn (cảnh báo), quy đổi tỷ lệ
- Cấp thành viên: Silver → Gold → Platinum → Diamond → VIP
- Nhiệm vụ nhận điểm; Quà sinh nhật; Quà lễ (Tết, 8/3, 20/10, Noel...)

### 1.9 Membership
- Lợi ích theo hạng: Giảm giá, ưu tiên đặt chỗ, quà tặng, hỗ trợ riêng, sự kiện exclusive
- Điều kiện duy trì: Chi tiêu tối thiểu, điểm tích lũy trong kỳ
- Progress bar lên hạng, cảnh báo gần bị hạ hạng
- Bảng so sánh lợi ích Silver / Gold / Platinum / Diamond / VIP

### 1.10 Gamification
- **Điểm danh hàng ngày**: Check-in nhận điểm, streak liên tiếp, thưởng milestone
- **Lucky Wheel**: Vòng quay may mắn, số lượt quay, quà trúng (voucher/điểm/hiện vật)
- **Mini Game**: Lắc điện thoại, nháy nhanh, ô chữ may mắn, game theo sự kiện
- **Săn Voucher**: Flash drop giới hạn thời gian và số lượng
- **Săn Coupon**: Coupon ẩn trong app, coupon khi scan QR tại địa điểm
- **Check-in nhận quà**: QR Check-in tại cửa hàng/sự kiện
- **Nhiệm vụ hàng ngày**: Xem 5 sản phẩm, chia sẻ 1 bài, thêm wishlist...
- **Nhiệm vụ hàng tuần**: Mua 1 đơn, đánh giá 3 sản phẩm, mời bạn bè...
- **Bảng xếp hạng**: Top tích điểm, mua sắm, check-in; Lọc tuần/tháng/toàn thời gian

### 1.11 Gift Card
- Mua: Chọn mệnh giá (cố định/tùy ý), tên người tặng, lời chúc, ảnh bìa
- Tặng: Gửi qua email, Zalo, SMS, link chia sẻ
- Lịch sử: Đã mua / nhận / sử dụng; Số dư từng thẻ
- Thanh toán bằng Gift Card tại checkout

### 1.12 E-Wallet (Ví điện tử)
- Nạp tiền: QR, VNPay, MoMo, ZaloPay, chuyển khoản ngân hàng
- Rút tiền: Về tài khoản ngân hàng, phí rút, giới hạn rút/ngày
- Thanh toán đơn hàng, dịch vụ; QR Pay tại quầy
- P2P chuyển tiền trong hệ thống (cho bạn bè)
- Lịch sử giao dịch đầy đủ, xuất sao kê PDF/Excel

### 1.13 QR Ecosystem
- **QR Check-in**: Điểm danh sự kiện, check-in shop nhận điểm loyalty
- **QR Parking**: Vé xe điện tử, quét vào/ra bãi
- **QR Payment**: QR cá nhân, quét QR cửa hàng thanh toán
- **QR Event**: Vé sự kiện điện tử, xác thực cổng vào
- **QR Loyalty**: Tích điểm nhanh tại quầy không cần app

### 1.14 Booking
- Đặt phòng họp: Danh sách phòng, thời gian, số người, dịch vụ kèm
- Đặt sân chơi: Sân thể thao, khu vui chơi, chọn slot giờ
- Đặt bàn nhà hàng: Ngày/giờ/số người, ghi chú đặc biệt
- Đặt dịch vụ: Spa, salon, làm đẹp, chọn nhân viên phục vụ
- Đặt phòng sự kiện: Hội trường, sảnh, báo giá tự động
- Quản lý lịch: Xem lịch đặt, hủy, đổi lịch, nhắc nhở

### 1.15 Smart Mall
- **Indoor Navigation**: Bản đồ 2D/3D, tìm điểm đến, chỉ đường từng bước (BLE beacon/WiFi RTT)
- **Smart Parking**: Tra slot trống real-time, dẫn đến bãi, thời gian dự kiến
- **Bản đồ 3D**: Mô hình 3D toàn mall, click vào gian hàng để xem info
- **Camera AI**: Thông báo khu vực đông người, tránh giờ cao điểm (ẩn danh)
- **WiFi Portal**: Đăng nhập WiFi miễn phí (SĐT/email/social login)

## 3. 🔧 ADMIN CMS

### 3.1 Dashboard
- **KPI Cards**: Tổng doanh thu, khách, đơn, cửa hàng; So sánh kỳ trước (%), AOV, NPS
- **AI Insight**: Nhận xét tự động từ AI (trend, nguyên nhân, đề xuất hành động)
- **Biểu đồ**: Doanh thu theo thời gian, đơn theo trạng thái, top sản phẩm/cửa hàng, traffic
- **Real-time**: Khách online, đơn đang xử lý, cảnh báo hệ thống
- **Quick Actions**: Tạo voucher nhanh, gửi thông báo, duyệt đơn chờ

### 3.2 User Management
- Admin / Nhân viên / Chủ shop / Khách hàng
- **RBAC**: Tạo/sửa/xóa role, gán quyền chi tiết theo module (view/create/edit/delete/export)
- Audit Log; Khóa/mở tài khoản, gộp tài khoản trùng SĐT/email

### 3.3 Store Management
- CRUD cửa hàng, bulk actions; Logo & Banner: Upload, crop, optimize
- Tầng & Gian hàng: Layout, vị trí bản đồ, polygon editor
- Hợp đồng thuê: PDF, ngày hiệu lực, phí, gia hạn, cảnh báo hết hạn
- Trạng thái: Hoạt động / Tạm đóng / Đang thi công / Chờ duyệt
- Review: Duyệt/ẩn/trả lời; Import/Export Excel

### 3.4 Product Management
- CRUD, clone, bulk actions; **AI Generate**: Sinh mô tả, tiêu đề SEO, tag
- Import Excel (preview, xử lý lỗi từng dòng); Export Excel (filter tùy chọn)
- QR Code + Barcode (EAN-13, Code128): Sinh và in
- Variant: Màu/size/chất liệu, giá/ảnh theo variant
- SEO: Meta title/description, slug, canonical, OG image
- Trạng thái: Published / Draft / Archived / Out of Stock

### 3.5 Inventory Management
- Danh sách kho (theo cửa hàng/tập trung), tồn kho hiện tại
- Nhập kho: Phiếu nhập, nhà cung cấp, QR/barcode scan
- Xuất kho: Phiếu xuất, ghi lý do (bán/trả NCC/hỏng)
- Kiểm kê: Phiên kiểm kê, QR/barcode scan, đối chiếu, biên bản
- Cảnh báo dưới mức tối thiểu, dự báo hết hàng (AI)

### 3.6 Order Management
- Danh sách: Lọc trạng thái/cửa hàng/ngày/phương thức; Tìm theo mã/tên khách
- Chi tiết: Sản phẩm, khách hàng, địa chỉ, vận chuyển, thanh toán, timeline
- Xử lý: Duyệt → Đóng gói → Giao shipper → Xác nhận thành công
- Thanh toán: Xác nhận COD thủ công, đối soát online
- Refund: Tạo yêu cầu, duyệt, hoàn tiền về nguồn/ví
- Export Excel/PDF, in phiếu giao hàng/hóa đơn

### 3.7 CRM (Customer)
- Hồ sơ 360°: Thông tin cá nhân, lịch sử mua, điểm, voucher, ticket, ghi chú
- Membership: Nâng/hạ hạng thủ công, thêm điểm bonus, lịch sử hạng
- Segmentation: Tạo nhóm theo điều kiện (RFM, hành vi, nhân khẩu học)
- Tặng voucher theo khách/nhóm; Ghi chú CRM timeline (cuộc gọi, email, gặp mặt)

### 3.8 Voucher Management
- CRUD: Mã cố định / mã tự động, bulk generate
- Điều kiện: Đơn tối thiểu, danh mục/sản phẩm/cửa hàng áp dụng, hạng, lần đầu
- Giới hạn: Số lần tổng, số lần/khách, thời hạn, ngân sách tối đa
- Loại giảm: % (max cap), số tiền cố định, freeship, mua X tặng Y
- Phân phối: Email, push, web, nhập thủ công
- Thống kê: Tỷ lệ sử dụng, doanh thu từ voucher, top cửa hàng dùng

### 3.9 Gift Card Management
- CRUD mẫu (design, mệnh giá), publish/unpublish
- Quản lý số dư: Danh sách phát hành, số dư còn lại, lịch sử sử dụng
- Phát hành: Bán lẻ, bán lô B2B, tặng từ admin
- Thiết kế: Upload ảnh bìa, màu, logo
- Báo cáo: Tổng phát hành, sử dụng, liability (số dư chưa dùng)

### 3.10 Wallet Management
- Xem số dư tất cả khách hàng, tổng tiền trong hệ thống
- Nạp thủ công (quà, bồi thường); Duyệt rút tiền, chuyển khoản ngân hàng
- Lịch sử giao dịch: Tìm kiếm, lọc, export; Đối soát với cổng thanh toán

### 3.11 Gamification (Admin)
- **Lucky Wheel**: Tạo vòng quay, cấu hình quà (xác suất/số lượng/loại), lịch chạy
- **Mini Game**: Tạo theo sự kiện, luật chơi, phần thưởng
- **Quest**: Nhiệm vụ hàng ngày/tuần/sự kiện, điều kiện hoàn thành, phần thưởng
- **Reward**: Catalog quà đổi, tồn kho quà, xử lý yêu cầu đổi quà
- **Leaderboard**: Tiêu chí, thời gian, phần thưởng cho top

### 3.12 Events Management
- CRUD sự kiện: Banner, mô tả, địa điểm, thời gian
- QR Check-in: Sinh QR, app scan, danh sách tham dự real-time
- Vé: Loại vé (miễn phí/trả phí), giới hạn, bán vé, xuất danh sách
- Thông báo nhắc nhở trước sự kiện
- Báo cáo: Số tham dự, check-in rate, doanh thu vé

### 3.13 News & Blog
- CRUD: WYSIWYG rich text, chèn ảnh/video
- SEO: Slug, meta title/description, OG image, canonical, sitemap tự động
- Phân loại: Danh mục, tag, series; Lên lịch đăng bài tự động
- Quản lý comment; Analytics: Lượt xem, thời gian đọc, bounce rate

### 3.14 Restaurant Management
- Menu: Danh mục món, tên/giá/ảnh/mô tả/allergen; Cập nhật nhanh
- Đặt bàn: Xác nhận, từ chối, đổi bàn, ghi chú
- Sơ đồ bàn: Trạng thái (trống/đặt/đang dùng), turnover time

### 3.15 Cinema Management
- Phim: CRUD (poster, trailer, thể loại, thời lượng, đạo diễn, diễn viên, rating)
- Lịch chiếu: Suất chiếu, phòng chiếu, sơ đồ ghế, giá theo loại ghế
- Vé: Quản lý đặt vé, xác nhận, xuất vé điện tử (QR)

```sql
-- ==================== AUTH & USERS ====================
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) UNIQUE,
  phone VARCHAR(20) UNIQUE,
  password_hash VARCHAR(255),
  full_name VARCHAR(255),
  avatar_url TEXT,
  date_of_birth DATE,
  gender VARCHAR(10),
  status VARCHAR(20) DEFAULT 'active',
  email_verified_at TIMESTAMP,
  phone_verified_at TIMESTAMP,
  two_factor_enabled BOOLEAN DEFAULT false,
  two_factor_secret TEXT,
  last_login_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE user_addresses (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  label VARCHAR(50),
  recipient_name VARCHAR(255),
  phone VARCHAR(20),
  province_code VARCHAR(10),
  district_code VARCHAR(10),
  ward_code VARCHAR(10),
  street_address TEXT,
  is_default BOOLEAN DEFAULT false,
  lat DECIMAL(10,7),
  lng DECIMAL(10,7),
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE stores (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  owner_id UUID REFERENCES users(id),
  name VARCHAR(255) NOT NULL,
  slug VARCHAR(255) UNIQUE NOT NULL,
  description TEXT,
  logo_url TEXT,
  banner_url TEXT,
  floor INT,
  unit VARCHAR(50),
  category_id UUID REFERENCES store_categories(id),
  phone VARCHAR(20),
  open_time TIME,
  close_time TIME,
  is_open BOOLEAN DEFAULT true,
  status VARCHAR(20) DEFAULT 'pending',
  rating DECIMAL(2,1) DEFAULT 0,
  total_reviews INT DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE products (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  store_id UUID REFERENCES stores(id),
  category_id UUID REFERENCES product_categories(id),
  name VARCHAR(500) NOT NULL,
  slug VARCHAR(500) UNIQUE NOT NULL,
  description TEXT,
  price DECIMAL(15,0) NOT NULL,
  compare_price DECIMAL(15,0),
  sku VARCHAR(100) UNIQUE,
  barcode VARCHAR(100),
  images JSONB DEFAULT '[]',
  attributes JSONB DEFAULT '{}',
  tags TEXT[],
  is_active BOOLEAN DEFAULT true,
  status VARCHAR(20) DEFAULT 'draft',
  rating DECIMAL(2,1) DEFAULT 0,
  total_reviews INT DEFAULT 0,
  total_sold INT DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE orders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_number VARCHAR(50) UNIQUE NOT NULL,
  user_id UUID REFERENCES users(id),
  store_id UUID REFERENCES stores(id),
  status VARCHAR(30) DEFAULT 'pending',
  subtotal DECIMAL(15,0) NOT NULL,
  shipping_fee DECIMAL(15,0) DEFAULT 0,
  discount_amount DECIMAL(15,0) DEFAULT 0,
  total DECIMAL(15,0) NOT NULL,
  payment_method VARCHAR(30),
  payment_status VARCHAR(20) DEFAULT 'pending',
  shipping_address JSONB,
  note TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE payments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_id UUID REFERENCES orders(id),
  user_id UUID REFERENCES users(id),
  payment_method VARCHAR(30) NOT NULL,
  transaction_id VARCHAR(255),
  amount DECIMAL(15,0) NOT NULL,
  status VARCHAR(20) DEFAULT 'pending',
  gateway_response JSONB,
  paid_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE loyalty_points (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  balance INT DEFAULT 0,
  lifetime_points INT DEFAULT 0,
  tier VARCHAR(20) DEFAULT 'silver',
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE vouchers (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  code VARCHAR(50) UNIQUE NOT NULL,
  type VARCHAR(20) NOT NULL,
  value DECIMAL(15,0) NOT NULL,
  max_discount DECIMAL(15,0),
  min_order DECIMAL(15,0) DEFAULT 0,
  usage_limit INT DEFAULT 0,
  usage_per_user INT DEFAULT 1,
  start_date TIMESTAMP,
  end_date TIMESTAMP,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE gift_cards (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  code VARCHAR(50) UNIQUE NOT NULL,
  owner_id UUID REFERENCES users(id),
  initial_balance DECIMAL(15,0) NOT NULL,
  current_balance DECIMAL(15,0) NOT NULL,
  status VARCHAR(20) DEFAULT 'active',
  expires_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE notifications (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  type VARCHAR(30) NOT NULL,
  title VARCHAR(255) NOT NULL,
  body TEXT,
  data JSONB,
  is_read BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE bookings (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  store_id UUID REFERENCES stores(id),
  type VARCHAR(30) NOT NULL,
  booking_date DATE NOT NULL,
  start_time TIME NOT NULL,
  end_time TIME NOT NULL,
  guests INT DEFAULT 1,
  status VARCHAR(20) DEFAULT 'pending',
  note TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE daily_checkins (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

  checkin_date DATE NOT NULL,

  points_earned INT DEFAULT 10,
  created_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(user_id, checkin_date)
```

## 37. 🏗️ DISASTER RECOVERY

### RPO/RTO Targets
| Tier | Systems | RPO | RTO |
|------|---------|-----|-----|
| Critical | Auth, Payment, Order | < 5 min | < 15 min |
| High | Product, Store, Cart | < 15 min | < 30 min |
| Medium | Loyalty, Notification | < 1 hour | < 2 hours |
| Low | Analytics, Reports | < 24 hours | < 8 hours |

### Recovery Procedures
```yaml
# Database Failover
1. Detect primary failure (Prometheus)
2. Promote replica (patroni auto-failover)
3. Update connection strings
RTO: < 30 seconds

# Service Failure
1. K8s auto-restart (liveness probe)
2. If 3 restarts fail → alert on-call
3. Rollback to previous version
RTO: < 2 minutes

# Region Failure
1. Route traffic to DR region (DNS)
2. Promote DR database replicas
3. Scale up DR services
RTO: < 4 hours, RPO: < 1 hour
```
